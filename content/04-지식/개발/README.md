# 개발 지식

[전체 지식 지도](<04-지식/README.md>)

`지식 → 개발 → 주제별 카테고리 → 문서` 구조입니다. 데이터, 시스템 설계, 디자인 등은 각각 독립된 카테고리로 구분합니다.

| 카테고리 | 내용 |
|---|---|
| [데이터](<04-지식/개발/데이터/README.md>) | 데이터베이스·SQL·데이터 모델링·시각화 |
| [인프라](<04-지식/개발/인프라/README.md>) | 네트워크·리눅스·클라우드·컨테이너 |
| [시스템 설계](<04-지식/개발/시스템 설계/README.md>) | 아키텍처·분산 시스템·설계 다이어그램·가용성 |
| [디자인](<04-지식/개발/디자인/README.md>) | 디자인 패턴·MVC·웹 접근성 |
| [프론트엔드](<04-지식/개발/프론트엔드/README.md>) | 웹 프레임워크·React·Angular·Svelte |
| [알고리즘](<04-지식/개발/알고리즘/README.md>) | 시간복잡도·알고리즘 분석 |
| [보안](<04-지식/개발/보안/README.md>) | 보안 요구사항·검증 기준 |
| [개발운영](<04-지식/개발/개발운영/README.md>) | 형상관리·CI/CD·배포·운영·인프라 자동화 |
| [AI](<04-지식/개발/AI/README.md>) | AI 코딩·LLM·AI 지식 도구 |
| [자동화](<04-지식/개발/자동화/README.md>) | n8n·워크플로 자동화 |
