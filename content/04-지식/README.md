## 정리 규칙

- 노트는 분야 폴더에 바로 저장하고, 세부 주제는 목차와 태그로 구분합니다.
- 논문요약·강의노트·트러블슈팅은 문서 형식 태그입니다.
- 문서 1~2개로 하위 폴더를 만들지 않습니다. 5개 이상 쌓이고 탐색에 도움이 될 때 분리합니다.
- 새 노트는 `publish: false`로 시작하고, 공개 여부는 직접 결정합니다.
