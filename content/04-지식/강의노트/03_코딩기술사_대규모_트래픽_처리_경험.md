## 개요 
채용 공고에 Kafka 대규모 처리 경험이 있는지 쓰여져 있는 경우가 많음
그에 따라 해당 "기술사"관점에서 대규모 트래픽 처리란 무엇인지 알려줌

## 국제표준에 있는것과 없는것

| ISO                                      | 없는것     |
| ---------------------------------------- | ------- |
| ISO/IEC 25010 - Time behaviour, Capacity | 대규모의 기준 |
| ISO/IEC 25023 - 평균 응답시간, 처리량 측정 함수       |         |

## 본 내용

	트래픽 측정 : RPS, CU, DAU
	처리 성능 : Latency, 가용성, 에러율, TPS
