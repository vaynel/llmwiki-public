## 작성 방식

1. 사용한 기사·공식 자료·유튜브 자막을 비공개 원자료 보관소에 먼저 저장하고, 출처·게시일·수집시각·보관 형식을 기록한다.
2. `market-brief` 스킬로 사실과 진행자 관점, 작성자 해석을 구분해 상세 보고서를 작성한다. 쟁점마다 근거와 의미, 판단을 바꿀 조건을 설명한다.
3. 비교는 표로, 수치의 분포와 변화는 차트로, 영향의 전달 과정은 다이어그램으로 보여 준다. 원자료와 수치·기준시점을 대조하고 시각 자료를 검토한다.
4. 검증한 보고서와 시각 자료를 이 공개 폴더에 보관한다. 출처 원문과 전체 자막은 비공개로 유지하며, 공개 보고서에는 원문 링크를 제공한다.
5. 보고서 작성·검증이 끝나면 사용한 sources 파일, 출처 대장, 수집 결과, 작성 스크립트, 검증·전달 기록은 비공개 `05-아카이브/증시분석/`으로 옮긴다. 프로젝트에는 보고서와 열람에 필요한 시각 자료·차트 데이터만 남긴다. 원문·전체 자막은 기존 `private/raw/` 원본 아카이브에 보존한다.

## 보고서 경로 규칙

연도 → 월_주 → 보고서 순서로 보관한다. 주차는 월요일 시작 달력에서 1일이 포함된 줄을 1주차로 계산한다. 월 경계에서는 보고서 작성일의 연도·월을 사용한다. 예: `2026/09_4주/2026-09-27_증시_현황_분석.md`, `2026/09_5주/2026-09-28_증시_주간전략.md`. 차트는 프로젝트의 `assets/YYYY-MM-DD/`에 유지하며 보고서에서는 `../../assets/` 상대 링크를 사용한다. 비공개 출처·검증·전달 기록과 raw의 기존 경로는 유지한다.
